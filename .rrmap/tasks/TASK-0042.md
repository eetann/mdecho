`mdecho --pr 123`のように、手元でブランチをチェックアウトしなくてもPRで変更された`.md`を開けるようにする。

## 前提・ハマりどころ

mdechoはディスク上のファイルを読み、ライブリロードする作りになっている。チェックアウトしないなら、ファイルの実体をどこかに用意しないといけない。

- 案1: `git fetch origin pull/123/head`したあと、一時ディレクトリに`git worktree add`する。終了時に後始末が必要
- 案2: `git show <ref>:<path>`で中身だけ読む。ライブリロードや相対リンク・画像の解決をどうするかが課題

`gh`に依存するか(PR番号からbaseを取れる)、純粋なgitだけでやるかも決める。

TASK-0040の`--git <base>`が先。それまでは`gh pr checkout 123 && mdecho --git main`で代用できる。
