# 箇条書きのサンプル

箇条書きの項目どうしの間隔と、ネストの深さを示す縦のガイド線を見比べるためのサンプルです。
AIが生成したMarkdownは階層の深い箇条書きが多く、項目が行間のままベタ詰めで並ぶと「どこまでが一つの項目か」「いまどの階層を読んでいるか」が分かりにくくなります。

項目の切れ目が見えるか、インデントの深さが線で追えるかを眺めてください。

## 比較用の文章

1. AIが生成した設計ドキュメントの箇条書きは一項目が長くなりやすく、二行以上に折り返した項目が続くと、行の切れ目と項目の切れ目が同じ間隔で並んでしまいます。
2. 項目のあいだに余白が無いと、区切りを担うのは行頭の番号や中黒だけになり、本文の左端まで視線を戻さないと項目が変わったことに気づけません。
3. 人間がレビューするときは上から順に読むのではなく、気になった項目を拾い読みするので、項目の塊が目で分かれて見えることが読む速さに直結します。
4. 逆に余白を空けすぎると一覧としてのまとまりが失われ、箇条書きなのか短い段落の連続なのかが判別しにくくなるため、行間より少し広い程度に収めます。
5. 項目のあいだだけを空けて項目の中の行間は変えないので、二行に折り返した項目は中身が詰まったまま、外側だけが離れて一つの塊に見えます。
6. 番号付きリストでは番号そのものが区切りとして働きますが、`10.` のように桁が増えると番号の幅が変わるため、余白があるほうが並びが安定して見えます。
7. 箇条書きの中にインラインコード(`--no-split-sentences`)やリンクが混ざると行の中がにぎやかになり、項目の境目がいっそう埋もれやすくなります。
8. ネストした項目では親の項目と子の項目が同じ間隔で並ぶので、インデントの深さだけが階層を示す手がかりになっています。
9. 縦のガイド線を引くと、折り返して二行になった項目でも、その項目がどの親にぶら下がっているのかを線をたどって確認できます。
10. 項目の間隔とガイド線は別々の変更ですが、どちらも「一つの項目の範囲」と「階層」を目で分かるようにするという同じ目的を持っています。

## ネストした箇条書き

- 第一階層の項目です。この項目のように二行以上へ折り返す長さになると、項目の内側の行間と項目どうしの間隔のバランスが見えてきます。
  - 第二階層の項目です。親の項目からどれだけ内側に入っているのかを、インデントだけで判断している状態を確かめてください。
    - 第三階層の項目です。ここまで深くなると、どの項目にぶら下がっているのかを左端の位置から目で追うのが難しくなります。
      - 第四階層の項目です。AIが生成したドキュメントでは、細かい条件を並べるときにこのくらいの深さになることがあります。
    - 第三階層へ戻った項目です。一つ上の項目と同じ階層に並んでいることが分かるかどうかが見どころです。
  - 第二階層へ戻った項目です。間に深い階層を挟んだあとでも、親子の関係が追えるかを確かめてください。
- 第一階層へ戻った項目です。深いネストを抜けたあと、最初の階層に戻ってきたことがひと目で分かるでしょうか。

## 番号付きリストのネスト

1. 手順の一つ目です。番号付きのリストでも同じように階層を作れます。
   1. 入れ子の手順です。親の番号との関係が分かるかを確かめてください。
   2. 二つ目の入れ子の手順です。項目が短いときの間隔の見え方も一緒に見ておきます。
2. 手順の二つ目です。
   - 番号付きの項目の下に、中黒の箇条書きをぶら下げることもできます。
   - 種類が変わっても階層の見え方が揃っているかを確かめる場所です。
3. 手順の三つ目です。

## 項目の中に段落やコードブロックがある場合

- 項目の中に段落が二つ以上ある、いわゆるルーズリストです。

  この二つ目の段落は項目の一部ですが、項目の中の段落と項目どうしの区切りが同じ間隔だと、どちらの切れ目なのかが読み取れません。

- コードブロックを含む項目です。

  ```ts
  export function greet(name: string): string {
    return `こんにちは、${name}さん。`;
  }
  ```

- 最後の項目です。ここまでが一つの箇条書きであることが分かるかを確かめてください。

## 短い項目が続く場合

- 短い項目。
- これも短い項目。
- 一覧としてのまとまりが失われていないかを見る場所です。
- 余白が広すぎると、ここがバラバラに見えはじめます。

## チェックボックス

- [x] 済みの項目です。行頭にチェックボックスが入る場合の間隔を確かめます。
- [ ] 未着手の項目です。
  - [ ] ネストしたチェックボックスです。チェックボックスとガイド線が重ならないかを見ておきます。

## 引用の中

> レビューコメントを引用として貼り付けると、その中に箇条書きが入っていることがよくあります。
>
> - 引用の左の罫線と、箇条書きのガイド線が並ぶ場所です。
>   - ネストするとさらに線が増えるので、うるさくなっていないかを確かめてください。
> - 二つ目の項目です。
