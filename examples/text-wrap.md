# text-wrap: pretty / balance の見え方くらべ

段落の`text-wrap: pretty`と、見出しの`text-wrap: balance`を入れる前と後で、行の切れ方がどう変わるかを見比べるためのサンプルです。
`pretty`は段落のいちばん下の行に短い語だけが取り残される「行末の孤立語」を減らし、`balance`は見出しの各行の長さを揃えます。

Chromium系(Chrome / Edge)では両方とも効きます。
Firefoxは`balance`だけに対応していて`pretty`は解釈されませんが、効かないときは通常の折返しに戻るだけなので表示が崩れることはありません。

## 段落の行末(text-wrap: pretty)

下の10個は、最後の行に残る文字数が少しずつ増えるように長さを変えてあります。
入れる前は最後の行に数文字しか残らないものが混ざりますが、入れた後はその行へ前の行から文字が送られてきます。

(1) 行末の孤立語とは、段落のいちばん下の行に短い語や記号だけがぽつんと取り残されてしまっている状態のことを指します。

(2) 最後の行がほんの数文字だけで終わっていると、そこで段落が切れているのかどうかが目で追いにくくなってしまいます。

(3) 設定を入れる前と後で、この段落のいちばん下の行に何文字ぶんの文字が残っているのかを、上から順番に見比べてみてください。

(4) ブラウザは行を詰められるだけ詰めていくので、たまたま最後の行に短い語だけがひとつ残ってしまうことがわりとよくあります。

(5) prettyを入れると、ひとつ前の行から文字がいくらか送られてきて、最後の行がある程度の長さになるように調整されます。

(6) 調整されるのは最後の数行だけなので、段落の上のほうにある行の切れ方については入れる前とほとんど変わらないままです。

(7) 日本語では文節の区切りで折り返すword-breakの設定と組み合わせても、お互いを打ち消すことなく問題なく一緒に働いてくれます。

(8) 長さを少しずつ変えた文章をこうしていくつも並べておくと、どのくらいの長さのときに差が出るのかをずいぶん見つけやすくなります。

(9) もともと最後の行が十分に長くなっている段落では前後で見た目が変わらないので、効果の出ない例もここにはいくつか混ざっています。

(10) ウィンドウの幅を変えたり設定モーダルのほうで本文の幅を変えたりすると、差が出てくる段落の組み合わせもそのたびに変わっていきます。

### 箇条書きの中でも効く

- 箇条書きの項目にも段落とまったく同じように折返しが起きるので、ここでもいちばん下の行の長さが揃うようになります。
- マーカーのぶんだけ本文の幅が狭くなるため、段落に比べると短めの文でも2行になって違いを見つけやすくなります。
  - ネストするとそのぶんさらに本文が狭くなるので、行末に短い語だけがぽつんと取り残されやすい状況を作れます。

### 引用の中でも効く

> 引用ブロックは左の罫線と余白のぶんだけ本文の幅が狭くなるため、段落に比べると短めの文でも折返しが発生します。
> 引用の中でもいちばん下の行に短い語だけがぽつんと取り残されていないかどうかを、あわせて確かめてみてください。

## 見出しの行の揃え(text-wrap: balance)

下の10個の見出しは長さを少しずつ変えてあります。
入れる前は1行目が目一杯まで伸びて2行目が極端に短くなりますが、入れた後は2行の長さがおおよそ半分ずつに揃います。

### (1) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまで伸びてしまう例

### (2) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまで長く伸びてしまう例

### (3) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びてしまう例

### (4) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまう例

### (5) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまっている例

### (6) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまっているような例

### (7) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまっているような困った例

### (8) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまっているようなちょっと困った例

### (9) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまっているような少し見栄えの悪い例

### (10) 見出しが2行になったときに1行目だけが目一杯の幅いっぱいになるところまでずっと長く伸びきってしまっているようなあまり見栄えの良くない例

## 影響を受けない場所

コードブロックは横スクロールするので、この設定の影響を受けません。

```ts
// 日本語のコメントを書いても、ここでは折り返しが起きずに横へ伸びていきます。
export function greet(name: string): string {
  return `こんにちは、${name}さん。`;
}
```

表のセルはカラム幅の計算をこのツール側で行っているため、今回は対象に入れていません。

| 項目 | 説明 |
| :--- | :--- |
| 折り返し | セルの幅は内容にあわせて決まるため、長い説明文を入れると表の中でも折り返しが起きます。 |
| 行末の孤立語 | 表の中では`text-wrap`を指定していないので、ここの見え方は前後で変わりません。 |
