# テーブルのゼブラ縞のサンプル

表の行を目で追えるかを見比べるためのサンプルです。`th`の背景色だけだと、横に長い表で右端のセルまで視線を動かしたときに、いま何行目を読んでいたのかが分からなくなります。偶数行に薄い縞を敷いて、行方向の手がかりを足しています。

右端まで視線を動かしてから元の行に戻れるか、セルの中のインラインコードが縞に埋もれていないか、ヘッダーの行が縞と区別できるかを眺めてください。右上の「拡大」ボタンでモーダルを開くと、sticky headerの下を縞の行が流れていく様子も確認できます。

## 横に長い表

| オプション名 | 型 | デフォルト値 | 必須 | 説明 | 例 |
| --- | --- | --- | --- | --- | --- |
| `--port` | number | 4317 | 任意 | プレビューサーバーが待ち受けるポート番号を指定します。 | `--port 8080` |
| `--host` | string | "127.0.0.1" | 任意 | 待ち受けるホストを指定します。LAN内の別端末から開くときに使います。 | `--host 0.0.0.0` |
| `--no-open` | boolean | false | 任意 | 起動時にブラウザを自動で開かないようにします。 | `--no-open` |
| `--theme` | "light" \| "dark" | "light" | 任意 | プレビューの配色テーマを切り替えます。 | `--theme dark` |
| `--line-break` | "br" \| "paragraph" | "br" | 任意 | 単一改行の扱いを指定します。句点ごとの改行にも対応します。 | `--line-break paragraph` |
| `--comments-dir` | string | ".mdecho" | 任意 | コメントデータを保存するディレクトリを指定します。 | `--comments-dir .notes` |
| `--watch` | boolean | true | 任意 | ファイル変更を検知して自動リロードするかどうかを指定します。 | `--watch=false` |
| `--content-width` | string | "1024px" | 任意 | 本文カラムの最大幅を指定します。長い表を広く見せたいときに使います。 | `--content-width 1280px` |
| `--font-body` | string | (システム既定) | 任意 | 本文のフォントを指定します。指定したものが既定のスタックの手前に入ります。 | `--font-body "BIZ UDPGothic"` |
| `--font-code` | string | (システム既定) | 任意 | コードブロックとインラインコードのフォントを指定します。 | `--font-code "Cascadia Code"` |
| `--split-sentences` | boolean | true | 任意 | 句点ごとに行を分けて、コメントを文単位で付けられるようにします。 | `--no-split-sentences` |
| `--quiet` | boolean | false | 任意 | 起動時のログを抑えて、URLの1行だけを出力します。 | `--quiet` |
| `--config` | string | (自動探索) | 任意 | 設定ファイルのパスを明示します。省略時は設定ディレクトリを自動で探します。 | `--config ./mdecho.jsonc` |
| `--version` | boolean | false | 任意 | バージョンを表示して終了します。 | `--version` |

## 短い表

行数が少ない表で、縞がうるさく見えないかを確かめます。

| 項目 | 値 |
| --- | --- |
| ポート | 4317 |
| テーマ | light |

## セルが折り返す表

セルの中身が二行以上に折り返したときに、縞が「1セル」ではなく「1行」の範囲を示せているかを確かめます。

| 状況 | 起きること | 対処 |
| --- | --- | --- |
| 指定したポートがすでに使われている | 起動に失敗してエラーメッセージが出ます。ほかのプロセスが同じポートを掴んでいる状態です。 | `--port`で別の番号を指定するか、そのプロセスを終了してから起動し直します。 |
| 監視対象のファイルが外部ツールに置き換えられた | エディタの保存方式によっては、変更検知が一度だけ空振りすることがあります。 | ブラウザを手動で再読み込みするか、`--watch=false`にしてから必要なときだけ読み込みます。 |
| コメントの保存先がGitの管理下にある | コメントのJSONが差分に混ざって、コミットのたびにノイズになります。 | `--comments-dir`で管理外のディレクトリを指定するか、`.gitignore`に追加します。 |

## 引用の中の表

> | キー | 意味 |
> | --- | --- |
> | `j` / `k` | 次/前の行へカーソルを移動します。 |
> | `c` | カーソル行にコメントを書きます。 |
> | `?` | キーボードショートカットの一覧を開きます。 |
