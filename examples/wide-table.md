# mdecho 設定リファレンス

mdecho はローカルの Markdown ファイルをブラウザでプレビューし、行単位でコメントを残せるツールです。このページでは設定可能なオプションを一覧にしています。

## 概要

設定は起動時のコマンドライン引数、または `mdecho.config.json` で指定できます。多くの項目は省略時にデフォルト値が使われます。

## 設定オプション

| オプション名 | 型 | デフォルト値 | 必須 | 説明 | 例 |
| --- | --- | --- | --- | --- | --- |
| `--port` | number | 4317 | 任意 | プレビューサーバーが待ち受けるポート番号を指定します。 | `--port 8080` |
| `--no-open` | boolean | false | 任意 | 起動時にブラウザを自動で開かないようにします。 | `--no-open` |
| `--theme` | "light" \| "dark" | "light" | 任意 | Markdown プレビューの配色テーマを切り替えます。 | `--theme dark` |
| `--line-break` | "br" \| "paragraph" | "br" | 任意 | 単一改行の扱いを指定します。句点ごとの改行にも対応します。 | `--line-break paragraph` |
| `--comments-dir` | string | ".mdecho" | 任意 | コメントデータを保存するディレクトリを指定します。 | `--comments-dir .notes` |
| `--watch` | boolean | true | 任意 | ファイル変更を検知して自動リロードするかどうかを指定します。 | `--watch=false` |

## 使用例

```bash
mdecho --port 4317 --no-open ./docs/spec.md
```

上記のように起動すると、ブラウザを自動で開かずにサーバーだけを起動します。

## 補足

テーブルはセルの内容量からカラム幅を自動調整し、本文カラム内に収まります。文字が多いときはフォントが少しだけ小さくなります。右上の「拡大」ボタンで全画面表示に切り替えられ、列の境界をドラッグすれば幅を手動で調整できます(ダブルクリックで自動幅に戻ります)。
