# AIエージェントとの連携

mdechoは「AIが生成したMarkdownを人間がレビューし、コメントをAIに返す」という往復を支援するために作られています。

## 想定するワークフロー

1. AIエージェントがMarkdownドキュメント(設計書・レポートなど)を生成する
2. `mdecho -f <file>` を実行し、人間にレビューを依頼する
3. 人間はブラウザ上でドキュメントの気になる箇所を選ぶ(行頭の吹き出しをクリック、複数行ならその吹き出しを上下にドラッグ。ダブルクリックや範囲選択でも選べる)
4. 選択箇所に対してコメントを書き、変身ボタンでクリップボードにコピーする
5. 人間はコピーされたテキストをAIエージェントに貼り付ける
6. AIエージェントはそのテキストを読み、該当ファイルの該当行を修正する

## 参照情報の形式

クリップボードにコピーされるテキストは以下の形式です。

```markdown
path/to/file:L9
ここにコメント
```

複数行を選んだ場合(吹き出しのドラッグ、または範囲選択)は開始行と終了行の範囲になります。

```markdown
path/to/file:L9-L15
ここにコメント
```

`path/to/file` は `mdecho -f` に渡したファイルパス、`L9` はそのファイル内の行番号を指します。AIエージェントはこの形式を読み取ることで、レビュー対象のファイルと行を機械的に特定できます。

## 複数ファイルにまたがるレビュー

人間は `./foo.md` のようなリンクを辿って、同じディレクトリにある他のMarkdownも読み進められます。リンク先で書いたコメントの参照パスは、`-f` と同じ書き方でそのファイルを指します(`-f docs/index.md` から `./foo.md` を開いた場合は `docs/foo.md`)。

コピーボタンは、リンク先で書いたコメントもまとめて1回でコピーします。参照パスがそれぞれのファイルを指すため、複数のファイルへの指摘が1回の貼り付けで届きます。ボタンには対象のコメント数が出ます(例: `Copy (5)`)。
