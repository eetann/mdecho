# AIエージェントとの連携

mdechoは「AIが生成したMarkdownを人間がレビューし、コメントをAIに返す」という往復を支援するために作られています。

## 想定するワークフロー

1. AIエージェントがMarkdownドキュメント(設計書・レポートなど)を生成する
2. `mdecho -f <file>` を実行し、人間にレビューを依頼する
3. 人間はブラウザ上でドキュメントの気になる箇所を選ぶ(行頭の吹き出しをクリック、複数行ならその吹き出しを上下にドラッグ。ダブルクリックや範囲選択でも選べる)
4. 選択箇所に対してコメントを書き、変身ボタンでクリップボードにコピーする
5. 人間はコピーされたテキストをAIエージェントに貼り付ける
6. AIエージェントはそのテキストを読み、該当ファイルの該当行を修正する

## 参照情報の形式

クリップボードにコピーされるテキストは、既定では以下の形式です。ファイルごとに見出しでまとめ、その下に行番号とコメントが並びます。

```markdown
## path/to/file

L9:
ここにコメント

L12-15:
複数行を選んだ場合(吹き出しのドラッグ、または範囲選択)は開始行と終了行の範囲になる
```

`path/to/file` は `mdecho -f` に渡したファイルパス、`L9` はそのファイル内の行番号を指します。

設定(`clipboard.format: "inline"`)によっては、コメントごとにパスが付いた形式になります。

```markdown
path/to/file:L9
ここにコメント

---

path/to/file:L12-L15
ここにコメント
```

どちらの形式でも、AIエージェントはこれを読み取ることで、レビュー対象のファイルと行を機械的に特定できます。

## 複数ファイルにまたがるレビュー

レビューしてほしいファイルが複数あるときは、まとめて渡します。人間は1つのタブの中でファイル一覧から切り替えて読み、全ファイルへのコメントを1回でコピーできます。

```bash
mdecho docs/*.md
mdecho -f plan.md -f review.md
```

参照パスは、それぞれのファイルを渡したときの書き方になります。コピーしたテキストでは、渡した順にファイルが並びます。

人間は `./foo.md` や `../README.md` のようなリンクを辿って、カレントディレクトリの中にある他のMarkdownも読み進められます。リンク先で書いたコメントの参照パスは、`-f` と同じ書き方でそのファイルを指します(`-f docs/index.md` から `./foo.md` を開いた場合は `docs/foo.md`)。

コピーボタンは、リンク先で書いたコメントもまとめて1回でコピーします。参照パスがそれぞれのファイルを指すため、複数のファイルへの指摘が1回の貼り付けで届きます。ボタンには対象のコメント数が出ます(例: `Copy (5)`)。
