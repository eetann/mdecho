# トラブルシューティング

## `dist/client/index.htmlが見つかりません` と表示される

クライアント資産がビルドされていません。以下を実行してください。

```bash
bun run build:client
```

(npm経由でインストールした場合は、パッケージにビルド済み資産が同梱されているため通常発生しません。)

## `ファイルが見つかりません: <path>` と表示される

`-f` オプションに指定したパスが存在しないか、誤っています。カレントディレクトリと相対パスを確認してください。

## ブラウザが自動で開かない

`--no-open` オプションを指定している場合は意図した挙動です。ブラウザを開きたい場合はオプションを外してください。既定のブラウザを開けない環境では自動起動に失敗することがあります。その場合は、ターミナルに表示される `Listening on http://localhost:<port>/` のURLを手動で開いてください。

## 設定ファイルのフォント指定が反映されない

まず起動時のログに `Loaded config from ...` が出ているか確認してください。出ていなければ、設定ファイルのパス(`~/.config/mdecho/config.jsonc`)が違うか、構文エラーで読み込みをスキップしています。構文エラーの場合は `設定ファイルに構文エラーがあるため、既定の設定で起動します` という警告が出ます。

読み込めているのに見た目が変わらない場合は、指定したフォントがそのマシンにインストールされていない可能性があります。`mdecho font-ls` でフォント名の綴りを確認してください(出力の括弧内は別名なので、設定には括弧の前の名前だけを書きます)。mdechoは指定フォントを既定のフォントスタックの手前に差し込むだけなので、見つからないフォントは自動的に次の候補へフォールバックします。詳細は `mdecho docs show configuration` を参照してください。

## ポート番号が毎回変わる

mdechoは起動のたびに空いているポートを自動選択します。固定ポートの指定には現在対応していません。
