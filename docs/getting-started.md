# 基本的な使い方

## 起動

```bash
mdecho -f <file>
```

指定したMarkdownファイルをレンダリングするローカルサーバーが起動し、既定でブラウザが自動的に開きます。

## オプション

- `-f, --file <path>` (必須): 表示するMarkdownファイルのパス
- `--no-open`: 起動後にブラウザを自動で開かない
- `--no-split-sentences`: 句点(。)ごとの表示上の改行を無効化する
- `--no-single-newline`: 単一改行(Enterキー1回)を表示上の改行にしない(Markdown本来の扱いに戻す)

改行まわりは設定ファイルでも指定できます(`mdecho docs show configuration`)。

## ドキュメント内のリンク

`./foo.md` のような他のMarkdownへのリンクは、同じタブでmdechoがそのままレンダリングして表示します。リンク先でも行頭の吹き出しからコメントを書けます。

- 相対パスのリンクと画像は、そのMarkdownファイルのある場所と、プロジェクトルート(gitリポジトリのルート。リポジトリの外ならカレントディレクトリ)の両方を基準に探します。AIエージェントがリポジトリのルートから見たパス(`src/foo.ts` など)で書いたリンクも、深い場所のMarkdownから辿れます。
  - リンク先が両方に実在するときは、クリックするとどちらを開くか選ぶダイアログが出ます(Ctrl+クリックなどで新しいタブに開くときは、Markdownファイル基準の方を開きます)。
  - 画像は選べないため、両方にあるときはプロジェクトルート基準の方を表示します。
  - どちらか一方に決めたいときは、設定の `link.base` で切り替えます(`mdecho docs show configuration`)。
- `/docs/a.png` のように先頭が `/` のパスは、GitHubと同じくプロジェクトルート基準です。
- 開けるのは、次の「公開される範囲」の中にあるファイルだけです。`-f docs/plan.md` から `../README.md` を開くように、`-f` のファイルより上の階層でも、プロジェクトルートの中なら辿れます。
- ツールバー左のホームアイコンから、`-f` で指定したファイルへ戻れます。ブラウザの「戻る」も使えます。
- コメントはファイルごとに分かれて保存され、参照パスもそのファイルを指します。コピーボタンは開いているファイルだけでなく、リンク先で書いたコメントもまとめてコピーします(ボタンに対象の件数が出ます)。複数のファイルを見て回っても、AIエージェントへ渡すのは1回で済みます。
- 「すべてのコメントを削除」も同じく、他のファイルで書いたコメントまで消します。確認ダイアログに件数の内訳が出ます。
- `#見出し` のようなページ内リンクも効きます。見出しのidはGitHubと同じ規則で振るため、GitHub上で通用するアンカーがそのまま使えます。同じ見出しが複数ある場合は2つ目以降に `-1`、`-2` が付きます。
- `http(s)://` で始まる外部リンクは新しいタブで開きます。
- `javascript:` のような、開くとスクリプトが走るリンクは弾きます。弾いたリンクと画像は赤い打ち消し線と `⚠` で表示され、元のURLはマウスを乗せると出ます。

## 公開される範囲

プロジェクトルートの配下が、起動中のローカルサーバーから読める状態になります。`-f` のファイルがgitリポジトリの中ならそのリポジトリのルート、リポジトリの外ならカレントディレクトリです。ただし `-f /tmp/notes.md` のように、リポジトリの外かつカレントディレクトリの外にある場合は、そのファイルと同じディレクトリの配下だけに絞ります。ホームディレクトリそのものがgitリポジトリ(dotfilesの管理など)の場合は、そこをプロジェクトルートとはみなしません。読めるのは次の2種類だけです。

- Markdown (`.md` / `.markdown`) と、`-f` で指定したファイル自身
- 画像 (`.png` / `.jpg` / `.jpeg` / `.gif` / `.webp` / `.avif` / `.apng` / `.bmp` / `.ico` / `.svg`)

`.env` やソースコードなど、それ以外の拡張子のファイルは配信しません。ディレクトリの外を指すsymlinkも辿りません。

サーバーは `127.0.0.1` だけで待ち受けるため同じPCからしか開けず、ブラウザの全タブを閉じると終了します。とはいえ、リポジトリの中のファイルを開くと、どこで起動してもそのリポジトリのMarkdownと画像は同じPCの他のプロセスから読める状態になります。

## 目次

画面が十分に広いとき(1280px以上)、右端に見出しの一覧が出ます。見出しが無いファイルでは出ません。右上の `×` で折りたためます。

- 項目をクリックするとその見出しへ移動します。URLに `#見出し` が付くので、その位置のまま共有でき、ブラウザの「戻る」で元の位置へ戻れます。
- 今読んでいる見出しに青い罫線が付いて太字になります。本文の読み始めの高さまで上がってきた見出しが対象なので、節が長くて見出しが画面の外へ出ていても、直前に通り過ぎた見出しが残ります。ページの最下部では、末尾の節が短くてもその見出しが選ばれます。
- カーソル行(青い行)がいる見出しには、本文のカーソル行と同じ薄い青の下地が付きます。普段は上の印と同じ場所ですが、カーソルを置いたまま別の場所までスクロールすると2つに分かれるので、カーソルがどこにあるかを見失わずに戻れます。
- 見出しが多くて目次自体がスクロールするときは、今読んでいる見出しが見えるように目次側も動きます。

## 設定ファイル

ツールバー右上の歯車アイコンから、本文の幅・文字サイズ・行の高さや、本文・コードブロックのフォントを変更できます。変えるとその場で表示に反映され、「保存」で `~/.config/mdecho/config.jsonc` に書き込まれます。

設定ファイルを直接書くこともできます。使えるフォント名は `mdecho font-ls` で確認できます。詳細は [設定ファイル](./configuration.md) を参照してください。

## 終了方法

`Ctrl+C` (SIGINT) または `SIGTERM` でサーバーを終了できます。ブラウザの全タブを閉じた場合も自動的に終了します。

## ファイル変更の自動検知

表示中のMarkdownファイルを編集すると自動的に検知し、ブラウザがライブリロードされます。リンクを辿って別のファイルを開いているタブは、そのタブが表示しているファイルの変更だけでリロードされます。
